# BUYMA せどり目利き判定システム

BUYMA検索結果の画面録画(mp4)を投入し、過去データをもとに「この商品は買い（仕入れ）か」を
判定して見込み利益を試算するシステムです。

対象ブランド: PRADA、MARNI（拡張可）／ 対象カテゴリ: 財布・小物中心

## 構成

```
[PC] python app.py でサーバー起動（1つだけ）
   ↓ 同一Wi-Fi内
[スマホ or PC] ブラウザでアクセス（http://<PCのIP>:8000）
  ├─ 検索タブ:            商品名/型番で検索 → 判定・根拠・見込み利益を表示
  ├─ 動画アップロードタブ: 録画mp4を投入 → フレーム抽出→画像解析→DB反映を自動実行
  └─ 原価入力タブ:         現地買付原価を手動入力
```

## セットアップ（PC側・初回のみ）

```bash
cd buyma
python -m venv .venv && source .venv/bin/activate   # Windowsは .venv\Scripts\activate
pip install -r requirements.txt
```

必要なもの:

- **ffmpeg** — フレーム抽出に使用。`brew install ffmpeg` / `winget install ffmpeg` 等で導入
- **ANTHROPIC_API_KEY** — 画像解析にClaude APIを使用（従量課金）。
  `export ANTHROPIC_API_KEY=sk-ant-...` を設定してから起動してください。
  ※ APIキーがなくても検索・原価入力・判定は動作します（動画解析のみ不可）

## 起動

```bash
python app.py
```

起動時にスマホからアクセスするURL（`http://<PCのローカルIP>:8000`）が表示されます。
スマホをPCと同じWi-Fiに接続し、ブラウザでそのURLを開いてください。

## 運用フロー

1. スマホでBUYMAの検索結果（ブランド＋カテゴリ、人気順）をスクロール録画する
2. スマホのブラウザからWebアプリを開き、「動画アップロード」タブから録画を投入
3. サーバーが自動で フレーム抽出(ffmpeg) → 商品情報の画像認識(Claude API) → 重複排除 → SQLite保存 を実行
4. 完了すると「◯件のデータを追加しました」と表示される
5. 「検索」タブで商品名や型番を検索すると、判定（◎○△✕）・根拠・価格情報・見込み利益が表示される
6. 現地で買い付けた商品は「原価入力」タブで原価を記録すると、利益試算に反映される

## 判定ロジック（ルールベース）

| 基準 | 判定への影響 |
|---|---|
| 平均割引率（同カテゴリ平均比） | 高い → +2 |
| 評価数 | 10件以上 → +2 ／ 1〜9件 → +1 ／ 0件 → -1 |
| 出品者数 | 2名以上 → +2（需要が読めてる証拠） |
| 価格の時系列推移 | 直近7%以上の値下がり → -2 ／ 高値安定 → +1 |
| タグ（関税負担なし等） | 参考表示のみ |

スコア 4以上=◎買い候補 ／ 2〜3=○検討 ／ 0〜1=△様子見 ／ 負=✕見送り
（閾値は `judge.py` で調整できます）

見込み利益 = 直近平均販売価格 × 92.3%（BUYMA成約手数料概算控除）− 円換算原価（VAT還付控除後）

## 動作確認用サンプルデータ

実際の録画がまだ手元にない場合、ダミーデータで動作確認できます:

```bash
python seed_sample.py
```

※ 2026/6/21のPRADA分析を模したダミーです。実データ投入時はそのまま追記されます
（DBを作り直す場合は `data/buyma.db` を削除してください）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `app.py` | FastAPI Webサーバー（アップロード/検索/原価入力API + 画面） |
| `analyzer.py` | 動画→フレーム抽出→Claude画像認識→重複排除→DB保存 |
| `judge.py` | ルールベース判定ロジック |
| `db.py` | SQLiteスキーマ・商品マッチング |
| `static/index.html` | スマホ対応のWeb画面（3タブ） |
| `seed_sample.py` | 動作確認用ダミーデータ投入 |

データは `buyma/data/buyma.db`（SQLite）に保存されます。履歴として全件保持し、上書きしません。
